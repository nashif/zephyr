.. zephyr:code-sample:: renesas-ctsu-input
   :name: Renesas CTSU capacitive touch
   :relevant-api: input_interface

   Report presses on capacitive touch buttons and a slider through the input
   subsystem.

Overview
********

This sample reads the on-board capacitive touch controls of a Renesas RX board
through its Capacitive Touch Sensing Unit (CTSU), and reflects what it sees on
the board's LEDs.

Touch events arrive as input events, so the sample listens for them with an
input callback rather than polling the hardware. It handles two touch buttons
and a slider: each button press and release is reported on the console with a
running count of how many times that button has been pressed, and the slider
additionally reports its position, which the sample uses to choose which LED is
lit.

The CTSU needs per-board tuning data, since capacitive sensing depends on the
physical electrodes. That data is not written by hand: it is generated by the
Renesas QE for Capacitive Touch tool and lives in
:zephyr_file:`samples/boards/renesas/ctsu_input/src/qe_generated_files/`, which
the sample compiles in when
:kconfig:option:`CONFIG_INPUT_RENESAS_RX_QE_TOUCH_CFG` is set.

Requirements
************

A Renesas RX board with on-board CTSU touch electrodes and LEDs. An overlay is
provided for the :zephyr:board:`rsk_rx130` in its 512KB revision, which
describes the two buttons, the slider and the four LEDs the sample expects.
